# Known-broken fleet entries, one per line, as:
#
#     <package>/<runtime> :: <signature> :: <reason>
#
# All three fields are required, and the entry is still RUN.
#
#   <signature>  a substring that must appear in the suite's output for the
#                exemption to apply.
#   <reason>     why it is broken, in a sentence.
#
# Three rules. The first two come from ci/gate/fixture-sync-allow.txt, whose
# design problem was the same one; the third is why the signature exists:
#
#   - an entry with no reason is REJECTED, so a package cannot be quieted by
#     adding a bare name;
#   - an entry that PASSES fails the gate, so an exemption cannot outlive the
#     breakage it was written for -- an allow list goes on being obeyed long
#     after it stops being true, and the next real break lands in the space
#     it left;
#   - an entry that fails WITHOUT its signature fails the gate. "This package
#     fails" is not a claim worth recording: an exemption that accepts any
#     non-zero exit turns off regression detection for that package
#     altogether, so a second, newer break would ride in behind the first.
#
# A `#` is a comment only at the START of a line, so a signature may contain
# one -- and the most useful signatures do, being test-runner output such as
# `# fail 16`.
#
# An engine regression never goes here. The expr break on parser 0.9.1 was
# REAL and was meant to block: exempting it would have turned the gate off
# for the one regression it was built to catch. An entry is for a break that
# is the package's own, with the fix that removes it named.
#
# Since jsonic v0.7.12 (2026-11-12), jsonic's Go Make() declares lex.window
# (tabnas/jsonic#121). Six grammars' Go tests install their plugin on a
# plain jsonic.Make() and assert that the window is still off. Each pins
# jsonic v0.7.11 in its go.mod, and the fleet resolves jsonic to v0.7.12, so
# each test now measures jsonic's constructor, not the plugin. The fix is
# each grammar's own, as yaml v0.5.34's: install the plugin on a jsonic.Make
# whose window is turned off, and assert that it stays off. Delete an entry
# when its grammar releases that fix; the gate fails it until then.
csv/go :: the Csv plugin declares lex.window :: csv's TestMakeDeclaresTheWindow asserts that a plain jsonic.Make() is unwindowed, which jsonic v0.7.12 no longer is (tabnas/jsonic#121)

toml/go :: installing the grammar declares lex.window :: toml's TestMakeJsonicDeclaresTheWindow asserts that a plain jsonic.Make() is unwindowed, which jsonic v0.7.12 no longer is (tabnas/jsonic#121)
